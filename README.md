# jmfinizio.github.io

Personal website for Johnathan Finizio. It's a single static `index.html` with no build step.

## Publish on GitHub Pages
1. Create a new public repo named exactly **`Jmfinizio.github.io`**.
2. Upload `index.html` and `.nojekyll` to the repo root.
3. Go to **Settings → Pages**, set the source to **Deploy from a branch**, choose `main` / `(root)`, and save.
4. After a minute or two the site is live at **https://jmfinizio.github.io**.

Edit `index.html` and push to update the site.
